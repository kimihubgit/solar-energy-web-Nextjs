> Được xây dựng với **Next.js 16 (App Router)**, **React 19**, **TypeScript** và **Vanilla CSS**.

## 🌟 Tính năng nổi bật

- ⚡ **Full 73 Routes Pre-rendered**: Đầy đủ các trang Giới thiệu, Dịch vụ (kèm tư vấn theo hóa đơn tiền điện), Sản phẩm, Dự án thi công thực tế, Tin tức chuyên mục, Tuyển dụng và Liên hệ.
- 🎨 **Rich Aesthetics & Responsive UI**: Giao diện chuẩn mực, Dark & Eco-green theme, Glassmorphism, tối ưu hoàn hảo cho Desktop, Tablet và Mobile.
- 🧮 **Savings Calculator**: Công cụ trượt tính toán sản lượng điện sinh ra và chi phí tiết kiệm hàng tháng theo thời gian thực.
- 🖼️ **Lightbox Gallery**: Trình xem ảnh công trình sắc nét với điều hướng mũi tên và phím tắt.
- 📱 **Mobile Quick Actions**: Thanh điều hướng nhanh dưới đáy màn hình trên di động (Gọi ngay, Zalo, Báo giá).
- 🔍 **SEO, GEO, AIO & AEO Ready**:
  - `sitemap.xml` tự động tạo toàn bộ routes.
  - `robots.txt` tối ưu cho Googlebot và các AI Search Bot (GPTBot, PerplexityBot, ClaudeBot, v.v.).
  - Thẻ định vị địa lý GEO Meta Tags (Buôn Ma Thuột, Đắk Lắk).
  - Schema JSON-LD đa tầng: `LocalBusiness`, `Electrician`, `FAQPage` (tối ưu AI Overviews) và `WebSite`.
- 🔄 **Tích hợp CI/CD tự động**: Đã cấu hình GitHub Actions tự động kiểm tra Lint, TypeScript Types và Build Production khi push code.

## 🛠️ Cài đặt và Chạy cục bộ

```bash
# 1. Clone repository
git clone https://github.com/kimihubgit/solar-energy-web-Nextjs.git
cd solar-energy-web-Nextjs

# 2. Cài đặt dependencies
npm install

# 3. Khởi chạy môi trường phát triển
npm run dev
# Mở trình duyệt tại http://localhost:3000

# 4. Kiểm tra mã nguồn & Build
npm run lint
npm run build
```
