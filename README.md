# TH-EGO — Website Điện Mặt Trời & Kỹ Thuật Điện Đắk Lắk

Website giải pháp điện mặt trời, hệ thống lưu trữ Lithium và thi công điện trọn gói cho gia đình & doanh nghiệp tại Đắk Lắk.
Được xây dựng với **Next.js 16 (App Router)**, **React 19**, **TypeScript** và **Vanilla CSS**.

## Tính năng nổi bật

- ⚡ **Full 60+ Routes**: Đầy đủ các trang Giới thiệu, Dịch vụ (kèm tư vấn theo hóa đơn tiền điện), Sản phẩm, Dự án thi công thực tế, Tin tức chuyên mục, Tuyển dụng và Liên hệ.
- 🎨 **Rich Aesthetics & Responsive UI**: Giao diện sắc nét, Dark/Green theme, Glassmorphism, thiết kế tương thích mọi kích thước màn hình (Desktop, Tablet, Mobile).
- 🧮 **Savings Calculator**: Công cụ tương tác trượt tính toán sản lượng điện sinh ra và chi phí tiết kiệm hàng tháng theo thời gian thực.
- 🖼️ **Lightbox Gallery**: Trình xem ảnh công trình độ phân giải cao với điều hướng mũi tên và phím tắt.
- 📱 **Mobile Quick Actions**: Thanh điều hướng nhanh dưới đáy màn hình trên di động (Gọi ngay, Zalo, Báo giá).
- 🚀 **Tối ưu hóa hiệu năng**: 100% Pre-rendered tĩnh (Static Site Generation), chuẩn SEO thẻ meta và tải nhanh.

## Cài đặt và Chạy cục bộ

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Mở trình duyệt tại http://localhost:3000

# Build bản production
npm run build
```
